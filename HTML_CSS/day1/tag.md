# HTML 기본 태그 정리

프로필 페이지(`index.html`)에 쓴 태그 7개를 정리했습니다.

| 태그 | 한 줄 설명 | 닫는 태그 |
|---|---|---|
| `<head>` | 브라우저에 보이지 않는 문서 정보를 담는 영역 | 있음 |
| `<body>` | 화면에 실제로 보이는 내용을 담는 영역 | 있음 |
| `<p>` | 문단(paragraph) | 있음 |
| `<ul>` | 순서 없는 목록(unordered list) | 있음 |
| `<ol>` | 순서 있는 목록(ordered list) | 있음 |
| `<img>` | 이미지 삽입 | 없음 (빈 요소) |
| `<input>` | 사용자 입력칸 | 없음 (빈 요소) |

---

## 1. `<head>`

문서의 **정보(메타데이터)** 를 담는 영역입니다. 여기에 쓴 내용은 페이지 본문에 표시되지 않습니다.

주로 들어가는 것:
- `<meta charset="UTF-8">`: 문자 인코딩 지정. 이게 없으면 한글이 깨질 수 있습니다.
- `<title>`: 브라우저 탭에 표시되는 제목
- `<link>`, `<style>`: CSS 연결
- `<script>`: JavaScript 연결

```html
<head>
    <meta charset="UTF-8">
    <title>이채민 프로필</title>
</head>
```

---

## 2. `<body>`

화면에 **실제로 보이는 모든 내용**을 담는 영역입니다. 제목, 문단, 이미지, 표, 입력 폼 등이 전부 여기에 들어갑니다.

`<html>` 안에는 `<head>`와 `<body>`가 하나씩만 있어야 합니다.

```html
<html lang="ko">
<head> ... </head>
<body>
    <h1>Self Introduction.</h1>
    <p>안녕하세요!</p>
</body>
</html>
```

---

## 3. `<p>`

**문단(paragraph)** 을 만드는 태그입니다. 문단 위아래에 자동으로 여백이 생깁니다.

- 소스 코드에서 줄을 바꾸거나 공백을 여러 개 넣어도 화면에서는 공백 하나로 합쳐집니다.
- 문단 안에서 줄을 바꾸려면 `<br>`을 씁니다.
- `<p>` 안에 `<ul>`, `<div>` 같은 블록 요소를 넣으면 안 됩니다.

```html
<p>안녕하세요, 궁금한 건 직접 돌려봐야 직성이 풀리는 이채민입니다!</p>
```

---

## 4. `<ul>`

**순서가 중요하지 않은 목록**을 만듭니다. 각 항목은 `<li>`(list item)로 감쌉니다. 기본 표시는 점(●)입니다.

`type` 속성으로 기호 모양을 바꿀 수 있습니다.

| type | 모양 |
|---|---|
| `disc` (기본) | ● |
| `circle` | ○ |
| `square` | ■ |

```html
<ul type="square">
    <li>이름: 이채민</li>
    <li>MBTI: ISTP</li>
</ul>
```

> `type` 속성은 오래된 방식입니다. 요즘은 CSS의 `list-style-type: square;`를 더 많이 씁니다.

---

## 5. `<ol>`

**순서가 있는 목록**을 만듭니다. 항목은 `<ul>`과 마찬가지로 `<li>`로 감쌉니다. 번호는 자동으로 매겨집니다.

| 속성 | 설명 | 예시 |
|---|---|---|
| `type` | 번호 형식 | `1`(기본), `a`, `A`, `i`, `I` |
| `start` | 시작 번호 | `start="3"` → 3부터 시작 |
| `reversed` | 번호를 거꾸로 | 5, 4, 3, … |

```html
<ol type="i">
    <li>취미: 영화 보기</li>   <!-- i. -->
    <li>특기: 수영하기</li>    <!-- ii. -->
</ol>
```

**`<ul>`과 `<ol>` 고르는 기준**: 항목 순서를 바꿔도 의미가 같으면 `<ul>`, 순서가 바뀌면 의미가 달라지면(절차, 순위) `<ol>`을 씁니다.

---

## 6. `<img>`

**이미지**를 넣는 태그입니다. 내용을 감싸지 않으므로 닫는 태그가 없는 **빈 요소**입니다.

| 속성 | 설명 |
|---|---|
| `src` | 이미지 경로 (필수). 같은 폴더면 파일 이름만, 웹 이미지면 URL |
| `alt` | 이미지를 불러오지 못했을 때 표시되고, 스크린 리더가 읽는 대체 텍스트 |
| `width`, `height` | 표시 크기 (픽셀) |

```html
<img src="profile.jpg" alt="이채민 프로필 사진" width="200" height="200">
```

- `alt`는 접근성(시각 장애인 사용자)과 검색엔진 때문에 꼭 쓰는 게 좋습니다.
- `width`와 `height`를 원본 비율과 다르게 주면 이미지가 찌그러집니다. 하나만 지정하면 비율이 유지됩니다.

---

## 7. `<input>`

사용자에게 **값을 입력받는 칸**입니다. 주로 `<form>` 안에서 쓰고, 닫는 태그가 없는 빈 요소입니다.

`type` 속성에 따라 모양과 동작이 달라집니다.

| type | 용도 |
|---|---|
| `text` (기본) | 한 줄 글자 입력 |
| `email` | 이메일 입력. 제출할 때 `@` 형식을 자동으로 검사 |
| `password` | 입력한 글자가 ●로 가려짐 |
| `number` | 숫자만 입력 |
| `checkbox` | 여러 개 선택 |
| `radio` | 여러 개 중 하나만 선택 |
| `date` | 날짜 선택 |
| `submit` | 폼 전송 버튼 |

자주 쓰는 속성:

| 속성 | 설명 |
|---|---|
| `name` | 서버로 보낼 때 값의 이름 |
| `id` | `<label for="...">`와 연결할 때 사용 |
| `placeholder` | 입력 전 흐리게 보이는 안내 문구 |
| `required` | 비워두면 제출되지 않음 |
| `value` | 미리 채워둘 값 |

```html
<form>
    <label for="email">담당자 이메일:</label>
    <input type="email" id="email" name="email" placeholder="email@example.com">
    <button type="submit">이력서 전송하기</button>
</form>
```

> `<label>`의 `for` 값과 `<input>`의 `id` 값을 같게 하면, 라벨 글자를 클릭했을 때 입력칸에 커서가 들어갑니다.

---

## 전체 구조 한눈에 보기

```html
<!DOCTYPE html>
<html lang="ko">
<head>                         <!-- 보이지 않는 정보 -->
    <meta charset="UTF-8">
    <title>이채민 프로필</title>
</head>
<body>                         <!-- 화면에 보이는 내용 -->
    <img src="profile.jpg" alt="프로필 사진">
    <p>자기소개 문단</p>
    <ul> <li>순서 없는 항목</li> </ul>
    <ol> <li>순서 있는 항목</li> </ol>
    <form>
        <input type="text" placeholder="입력칸">
    </form>
</body>
</html>
```
